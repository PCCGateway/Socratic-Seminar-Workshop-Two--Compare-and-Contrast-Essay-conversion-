# Workshop 2 — Socratic Seminar to Compare & Contrast Essay

This GitHub Pages activity helps students turn their Socratic Seminar research and discussion notes into a compare-and-contrast essay.

## Computer-lab workflow
- **Upload My Socratic Seminar Notes** imports a JSON progress/notes file from the Socratic Seminar activity and prepopulates relevant blank essay-planning fields.
- **Upload Previous Essay Progress** resumes a saved Workshop 2 session on any computer.
- **Download & Save My Progress** creates a portable progress file for the next class period.
- **Download My Current Essay in Word** is intended to work even when the essay is incomplete.
- Browser autosave is only a same-computer backup.

Uploading seminar notes does not intentionally overwrite essay fields the student has already filled in.

## GitHub Pages
Upload all files in this folder to the repository root, then enable GitHub Pages under Settings > Pages.
